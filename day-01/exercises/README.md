# Day 1 – Programming Fundamentals & Employee Management

## Overview

This project is part of the 10-Day Intern Technical Training & Domain Assessment Program.

Day 1 focuses on programming fundamentals, basic Data Structures and Algorithms (DSA), error handling, Git/GitHub, and a practical Employee Management CLI application.

* Node.js

## Employee Management CLI

The Employee Management application is a command-line application built using Node.js.

### Features

* Add Employee
* Update Employee
* Delete Employee
* Search Employee
* List All Employees
* Find Employee with Highest Salary
* Calculate Average Salary
* Filter Employees by Department
* Input Validation
* Error Handling

### Employee Details

Each employee contains:

* ID
* Name
* Age
* Department
* Salary

## How to Run Employee Management

Open the terminal inside the `day-01` folder and run:

```powershell
cd employee-management
node app.js
```

The application will display the menu:

```text
1. Add Employee
2. Update Employee
3. Delete Employee
4. Search Employee
5. List Employees
6. Highest Salary
7. Average Salary
8. Department Filter
9. Exit
```

## How to Run Programming Exercises

Go to the exercises folder:

```powershell
cd exercises
```

Run any exercise using:

```powershell
node filename.js
```

For example:

```powershell
node reverse-string.js
```
